# The Acquisition Files

A study game for FAC-COR, FAC-P/PM, and the CFCM exam. Open `index.html` in a browser, or play the deployed site.

The game opens on Home: it asks what you're studying for, guides your first file step by step, and then always shows one next step. More of the station opens as you go.

Every catalogued objective moves through the same five stages: Watch, Work together, Independent, Connect, and Lead. One cast of characters keeps the same job titles across the restoration adventure, the Records Hall files, the story cases, and the station.

All scenarios, names, records, and figures are original and fictional. This is practice material, not certification, approved training hours, or NCMA/FAI material. Progress saves in the browser you play in; use Menu → Export and Import to move it between devices.
